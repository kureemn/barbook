# Prompts: rest timer

## How the feature was chosen

The plan's third custom feature was CSV import. After the agent explained what it would look like:

> I don't really use Excel, so I don't know if this is the best use of my feature. The worst?

I also considered an AI coach, but the agent laid out that it would need a paid API key and a spending limit, and I decided against it:

> Hmm, let's do something simpler.  A rest timer would be more useful for me

## What the agent did

It added a timer bar to the workout form with one-tap presets, +30 seconds, and an alert at the end, and it works from the end time so it stays correct if the phone pauses the page. It tested it through my real login, but it can't hear a beep or feel a vibration, so those are for me to check on my phone.

## Moving the timer to each set

> the timer should be after each set. So

The message was cut off. The agent took it to mean each set should have its own way to start a rest, and asked me to correct it if I meant something else. It added a Rest button under every set. I pick the rest length once in the bottom bar, and the app remembers it.

## Keeping it in one place

> It's setup weird, the rest button at the bottom but alsoembedded in the sets

The agent removed the bottom bar. Everything now sits under each set: a Rest button with a length menu, then the countdown with +30 seconds and Stop.
