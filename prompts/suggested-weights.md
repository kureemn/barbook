# Prompts: suggested weights

## Starting the feature

> Yes, start suggestions

Sent after the agent asked whether to start feature 9. The feature and its formula are described in `PLAN.md`.

## What the agent did

It wrote the formula and tests first, using the plan's two examples, then filled suggestions into the workout form when starting from a template. It checked the numbers against my real history with a template and workout labeled "TEST", which it then deleted.

The plan didn't say what to do when a template has no target RPE. The agent chose to aim for the same effort as the last set, since treating the target as RPE 10 would suggest an all-out set.
